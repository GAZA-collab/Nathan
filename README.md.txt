6. ICU and KAIST – Explains the 2009 merger.

 2.) The <header> contains the main website heading and introduction. The <nav> contains the navigation links. The <main> contains the primary content of the website. Inside <main>, I used <section> elements to divide the website into areas such as About, History, and ICU Zambia.

Using semantic elements makes the HTML easier to read, maintain, and understand. It can also improve accessibility and help search engines understand the structure of the page.

3.)  The <section> element was the most useful for organizing my layout because it allowed me to divide the website into clearly defined areas. Each section could focus on a particular topic, such as ICU's history, international reach, or contact information.

Q3.) <href> – This attribute makes navigation links functional by specifying the destination of a link.

<src>– This attribute tells the browser where to find an image displayed using the <img> element.

<id>– This attribute gives an element a unique identifier. I used IDs for different sections so that navigation links could take the visitor directly to a specific part of the page.


2. I used the <id> attribute to uniquely identify individual elements or sections. For example, I could give the History section the ID history and create a navigation link pointing to history.
The <class> attribute was used to group multiple elements together. Several historical articles could have the same class because they belong to the same category.

3. The <alt> attribute helped improve the user experience significantly. It provides alternative text for images. If an image cannot load, the visitor can still understand what the image represents.
The <title> attribute also provides additional information when users hover over certain elements, while `placeholder` gives users instructions when completing the feedback form.
